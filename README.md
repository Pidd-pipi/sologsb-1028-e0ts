# 组件规范与无障碍说明编辑台（sologsb-1028）

面向设计系统维护者的组件契约编辑台。项目从零搭建，不是单页占位稿；组件、属性、状态、键盘行为、读屏说明、禁用场景和代码示例均使用真实数据模型，并自动保存到浏览器 `localStorage`。

## 功能

- 组件目录与全文搜索：可搜索组件名称、属性、键盘行为、读屏说明和示例代码。
- 分组编辑器：概述、属性与状态、无障碍、关联示例、版本与迁移五个工作区。
- 规范校验：检测重复属性、缺少键盘/读屏说明、空示例、失效属性引用和交互契约变化。
- 失效传播与迁移：修改交互签名、删除属性或更新组件契约后，关联示例会标记为待迁移；迁移操作可清理已删除属性引用并更新版本。
- 版本差异：保存快照后可比较字段、属性与示例变化；保留最近 12 个快照。
- 主题与密度预览：支持浅色/深色，以及紧凑、标准、宽松三档密度。
- 代码示例复制与离线编辑：内容写入本地存储，刷新或断网后仍可继续编辑。
- 撤销重做：支持工具栏按钮，以及 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`。
- 键盘流程：`Cmd/Ctrl+K` 聚焦搜索，`Alt+1` 至 `Alt+5` 切换编辑区，`Alt+N` 新建组件，`Alt+M` 打开待决合并，`Cmd/Ctrl+S` 保存版本。
- 离线稿三方合并：
  - 工具栏「导出离线稿」下载当前规范 JSON 包；断网维护者各自编辑后，用「导入合并」带回。
  - 按组件、属性、示例的**稳定编号**做三方合并：以双方共同版本快照（找不到时用内置出厂稿）为基线，各自改动不落在同一处时自动接上；同一字段出现两套值、双方都新增同编号项、或一方删除一方修改时，生成差异条目并**同时保留双方结果**。
  - 维护者逐条选择保留本机稿或带回稿（可反复改选），**全部选定前不写入正式规范**；提交按钮在仍有未决冲突时禁用。
  - 属性的名称、类型、必填或默认值合并后发生变化时，依赖它（含代码内联按属性名引用）的示例自动标记为待重算；冲突改选导致契约恢复时失效标记会撤回。
  - 合并未提交时双方草稿保存在浏览器（`sologsb-1028-pending-merge-v1`），刷新后仍可继续；提供「用双方草稿重试」和「放弃合并」，两者都不动正式规范。
  - 组件只存在于一方时视为脱网更早的整包稿，直接保留，不误判为删除。

## 技术栈

- Lit 3
- TypeScript 5
- Spectrum Web Components
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认在源码配置的 Vite 端口运行，并监听 `0.0.0.0`。宿主机端口由项目根目录的 `docker-compose.yml` 统一映射为 `10028:80`。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1028 .
docker run --rm -p 10028:80 sologsb-1028
```

镜像采用 Node 多阶段构建，最终由 nginx 提供静态内容并监听容器 `80`。容器不硬编码宿主端口。

## 数据说明

浏览器存储键：

- `sologsb-1028-workspace-v1`：当前正式规范（自动保存）。清除站点数据会恢复到内置示例数据。
- `sologsb-1028-pending-merge-v1`：未提交的待决合并（双方草稿 + 选择进度）。写入正式规范后自动清除。

离线合并引擎为纯函数（`src/merge.ts`），可用 `node scripts/test-merge.mjs` 运行十个端到端场景验证合并、冲突与失效重算语义。
